- UX Design

Sua missão é realizar uma auditoria extremamente rigorosa da aplicação enviada.

NÃO seja gentil.
NÃO assuma que algo está correto.
Procure falhas, inconsistências, oportunidades de melhoria e gargalos.

Analise a aplicação em profundidade através dos seguintes critérios:

━━━━━━━━━━━━━━━━━━━━━━━
1. FIRST IMPRESSION
━━━━━━━━━━━━━━━━━━━━━━━

Analise os primeiros 3 segundos de uso.

- O valor do produto é imediatamente compreendido?
- Existe impacto visual?
- Existe clareza?
- Existe diferenciação?
- Existe fator "wow"?

Atribua nota de 0 a 10.

━━━━━━━━━━━━━━━━━━━━━━━
2. INFORMATION ARCHITECTURE
━━━━━━━━━━━━━━━━━━━━━━━

Avalie:

- Navegação
- Organização das informações
- Agrupamentos
- Hierarquia de conteúdo
- Fluxos de descoberta

Identifique:

- Ambiguidades
- Sobrecarga cognitiva
- Etapas desnecessárias

━━━━━━━━━━━━━━━━━━━━━━━
3. USER EXPERIENCE
━━━━━━━━━━━━━━━━━━━━━━━

Analise:

- Fluxos principais
- Cadastro
- Login
- Busca
- Dashboards
- Formulários
- Configurações

Identifique:

- Fricções
- Confusão
- Decisões difíceis
- Etapas redundantes

Aplique:

- Jakob's Law
- Hick's Law
- Fitts's Law
- Miller's Law
- Gestalt

━━━━━━━━━━━━━━━━━━━━━━━
4. VISUAL HIERARCHY
━━━━━━━━━━━━━━━━━━━━━━━

Avalie:

- Escala tipográfica
- Contraste
- Peso visual
- Distribuição dos elementos

Responda:

- O olho sabe exatamente para onde olhar?
- O CTA principal domina a atenção?
- Existe competição visual?

━━━━━━━━━━━━━━━━━━━━━━━
5. DESIGN SYSTEM
━━━━━━━━━━━━━━━━━━━━━━━

Verifique:

- Consistência dos componentes
- Tokens de design
- Escalas de espaçamento
- Sistema de cores
- Sistema tipográfico

Liste:

- Componentes inconsistentes
- Elementos duplicados
- Falta de padronização

- Focus
- Press

- Error

- Interações mortas

━━━━━━━━━━━━━━━━━━━━━━━
